# Security Policy

OXIM processes protected health information and accepts input from devices and networks, so we take security reports seriously.

## Supported versions

OXIM has not published a release yet. Until 1.0, only the `main` branch receives fixes, and it is not intended for production use. After 1.0 this section will list the supported release lines.

## Reporting a vulnerability

**Do not open a public issue for security problems.**

Report vulnerabilities privately through GitHub's private vulnerability reporting: open the repository's **Security** tab and choose **Report a vulnerability**.

Please include:

- the affected component and version or commit,
- a description of the issue and its impact,
- steps to reproduce, ideally with a minimal synthetic input,
- any known mitigations.

Never include real patient data in a report.

## What to expect

- We acknowledge a report within 5 working days.
- We confirm or dismiss the issue and share a remediation plan within 30 days.
- We coordinate disclosure with you and credit you in the advisory unless you prefer to stay anonymous.
